# Дополнение к маршрутам: RoboSelect

Все новые маршруты — HTML-интерфейс Django с сессионной авторизацией, а не новый публичный JSON API. Для POST требуется CSRF. Гость перенаправляется на вход; вошедший пользователь без `is_staff` получает 403. Источники и непроверенные наблюдения клиентам недоступны.

| Метод / путь | Назначение и параметры |
|---|---|
| GET `/workspace/robots/` | База роботов: `q`, `state=unreviewed/accepted/rejected`, `sort=name/-name/manufacturer/-manufacturer`, `page`. По 40 записей |
| GET `/workspace/robots/{id}/` | Наблюдения, текущий выбор, снимки, предложения, замечания и история |
| GET/POST `/workspace/robots/{id}/card/` | Дополнение производителя, комплектации, операций и поставщика для создания связанного черновика. Уже связанная модель ведёт на версию |
| POST `/workspace/observations/{id}/` | `decision=accepted/rejected`, `reason`. Отклонение требует причины; ненормализованное значение нельзя подтвердить |
| POST `/workspace/issues/{id}/resolve/` | Закрыть открытое замечание, обязательный `reason`; сохраняются сотрудник и время |
| GET `/workspace/snapshots/{id}/` | Скачать исходные байты, `application/octet-stream`, attachment, nosniff |
| GET `/workspace/sources/` | Список источников, статусы и ошибки |
| POST `/workspace/sources/` | `url` публичной HTTPS HTML-карточки. Синхронная обработка с сетевыми/размерными лимитами. Ошибка сохраняется в Source |
| POST `/workspace/parser/` | Существующий ZIP-импорт обновлён для 3.3.0. До 5 МБ ZIP, до 20 МБ/1000 файлов после распаковки |
| POST `/api/auth/login/` | Существующий JSON вход; необязательный `role=admin` дополнительно требует `is_staff` |
| POST `/api/auth/logout/` | Завершение текущей сессии |

`/api/auth/register/` удалён из urlpatterns: 404. Ни параметр `role`, ни переход по кнопке не назначают права. Аккаунты создаются через существующие административные средства.

Ошибки HTML-форм следуют существующему подходу workflow: возвращается страница с объяснением, без изменения публикации. Исходные значения экранируются Django, HTML снимка никогда не встраивается в страницу проверки. Публичный JSON API прежнего модуля по-прежнему описан в `openapi.json`; регистрацию в нём следует считать удалённой в этой версии.

## Последовательность проверки

1. Импортировать ZIP экспорта либо URL. `Source.status=review` означает наличие кандидатов, не успешную публикацию.
2. Открыть базу роботов и проверить исходные фразы/условия/дату. Выбрать подходящее значение или отклонить с причиной.
3. Закрыть устранённое замечание с объяснением; это не выбирает значение автоматически.
4. Если карточка ещё не создана, заполнить отсутствующие идентификационные сведения и назначение в связанной форме.
5. Проверить конкретную версию в ассортименте и опубликовать её. Для импортированных расчётных полей используются только выборы проверяющего. Прежние версии и расчёты сохраняются.

Изменение выбранного значения после публикации не переписывает предыдущую версию. Для отражения в клиентском каталоге создайте новую версию и отдельно опубликуйте её.
