- Новый модуль workflow, миграция 0001: поставщики/участники, версии каталога и доказательства, импорт по строкам, версии требований, конфигурации, заявки по поставщикам, сообщения, уведомления, демонстрационный заказ.

- domain.py: типизированная проверка требований и ТТХ, критические пропуски блокируют расчёт.
- selection.py: ограниченный перебор раздельных и совмещённых исполнителей, ранжирование по подтверждённости и TCO, ручная конфигурация.
- simulation.py: прототип DES на SimPy, DAG, общие группы, зарядка, проезды, буферы. Требует проверки граничных случаев и взаимоблокировок. Не геометрический планировщик.
- catalog.py: единый CSV, частичный импорт, модерация, импорт JSONL как черновиков; карточки парсера не получают автоматически подтверждённые цены/скорости с грузом/операции.
- views.py/urls.py: маршруты основных процессов. Все шаблоны, формы и стили созданы. Главная работает. Серверная проверка страниц и POST-переходов проходит.
- vendor/robot_parser: принятый офлайн-парсер, исправлен случай периодической цены без явного вида сделки. Документы CSV/TXT внутри для воспроизводимости. Парсер не имеет доступа к БД; импорт делает Django.
- Старое приложение доступно по /legacy/, старые API и модели сохранены.
