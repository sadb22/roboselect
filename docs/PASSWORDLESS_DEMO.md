# Свободный доступ без аккаунтов

На стартовой странице только «Вход как администратор» и «Вход как пользователь». Пароли и регистрация не нужны. Кнопки отправляют POST с CSRF на `/enter/admin/` и `/enter/user/`, выбирают роль в сессии и открывают соответствующий раздел.

Режим задаётся `PASSWORDLESS_DEMO=1`. При локальном `DEBUG=1` он включён по умолчанию. Для обычного запуска при `DEBUG=0` его нужно включить явно. В Render Blueprint и `scripts/render_start.py` деморежим включён по умолчанию; явная переменная `PASSWORDLESS_DEMO=0` отключает его. Роль по умолчанию — пользователь. Ассортимент, создание и редактирование роботов, источники, импорты и модерация доступны только после явного выбора роли администратора. Прямые URL и POST без этой роли получают 403. После переключения на пользователя права снимаются. Пункты управления скрыты в его меню. Выбор роли действует на текущую сессию браузера (включая её вкладки).

Это разделение ролей демонстрационного интерфейса: согласно запросу без паролей роль администратора можно выбрать на стартовой странице. Оно не удостоверяет личность реального администратора. При `PASSWORDLESS_DEMO=0` действуют прежние аккаунты и назначенные сотрудникам права.

Проекты привязаны к сессии браузера. Повторное открытие в том же браузере с действующими cookies сохраняет доступ; другой браузер/инкогнито получает отдельные проекты. Очистка cookies или истечение сессии создаёт новое рабочее пространство. Существующие проекты и аккаунты не удаляются; прежние проекты не появляются в списке проектов демопосетителя.

Для совместимости с имеющимися внешними ключами и историей изменений сервер создаёт внутреннего владельца без пригодного пароля, не выполняя Django login. Пользователь эту запись не создаёт и не видит. Права ограничены демонстрационной сессией; `PASSWORDLESS_DEMO=0` возвращает прежнюю систему доступа без сохранения административного входа у демопосетителей. CSRF продолжает действовать.

Старая ссылка `/account/` возвращает на выбор роли. `/admin/login/` открывает рабочее место только для уже выбранного администратора, иначе возвращает на стартовую страницу. Ни одна из этих ссылок не повышает права. `/api/auth/login/`, `/api/auth/logout/`, `/api/auth/register/` в деморежиме возвращают 404.

## Шаблон склада

На создании и редактировании проекта есть блок «Заполнить данные склада из файла»: скачать шаблон, выбрать заполненный CSV (UTF-8, разделитель `;`, до 2 МБ), загрузить данные в форму. Формат использует колонки `section`, `key`, `value`; значения чисел, списков операций и проездов — в формате JSON как в примере шаблона. CSV можно редактировать в табличном редакторе, сохраняя этот формат. XLSX в этом workflow-импорте не поддерживается.

Загрузка заполняет параметры склада, маршруты, операции и финансовые поля для проверки. Она не создаёт проект и не изменяет уже сохранённую версию. Для сохранения нужно отдельно нажать «Сохранить требования». Ошибки формата/диапазонов отображаются в той же форме; введённые до загрузки сведения сохраняются. Прежний импорт из списка проектов продолжает создавать новый проект из проверенного файла.

Проверки `core/test_demo_access.py`: открытие всех рабочих страниц без входа, отсутствие кнопок входа, сохранение и повторное открытие проекта, изоляция браузеров и прежних аккаунтов, запрет чужого удаления, сохранение CSRF, отсутствие оставшейся административной сессии при отключении режима.

Это дополнение заменяет прежние инструкции об обязательном создании аккаунта и двух кнопках входа в демонстрационном интерфейсе. Старые записи в DELIVERY/VALIDATION/TZ_COMPLIANCE описывают предыдущий этап работ. Сервер Render в ходе изменения не обновлялся.

Итог проверки: полный набор — 73 теста, OK (119,173 с). В Edge проверены 7 страниц при 1366×768 и 390×844 без авторизации, полей пароля, ошибок JavaScript и переполнения страницы. Django check — без ошибок.

Обновление стартовой страницы: / содержит только две кнопки «Вход как администратор» и «Вход как пользователь». Они открывают /workspace/robots/ и /user/ без запроса пароля. Прежняя главная с описанием, каталогом и примерами перенесена на /user/.

Проверка после разделения ролей и загрузки шаблона: 79 тестов, OK (91,885 с). В Edge на 1366×768 и 390×844 проверены выбор и переключение роли, блокировка административных URL для пользователя, скачивание CSV и загрузка в форму без автоматического сохранения. Миграций не требуется.
