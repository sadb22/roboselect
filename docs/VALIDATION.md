# Локальная проверка RoboSelect

Дата: 29 сентября 2026. Windows, Python 3.12, Django 5.2.17, SQLite. Исходная версия `1b19de3`. Проверки выполнялись на локальной рабочей копии, без обращения к производственной БД.

| Проверка | Результат |
|---|---|
| `python manage.py test core workflow --noinput` | **67 тестов, OK**, 34,827 с в окончательном полном прогоне |
| `python -m unittest discover -s vendor/robot_parser/tests -v` | **20 тестов, OK**, 1,422 с |
| `python manage.py check` | Ошибок нет |
| `python manage.py makemigrations --check --dry-run` | Неучтённых изменений моделей нет |
| `python manage.py migrate` | Все миграции применены на локальной SQLite |
| Перенос непустой базы | `test_existing_rows_and_published_revision_survive`: прежний указатель публикации, данные и JSON-доказательства сохранены |
| Повторный импорт | Повторный запуск парсера с новым временем обработки возвращает тот же пакет, не размножает модели/наблюдения и не сбрасывает решение проверяющего |
| Новый конфликт | Новое несовпадающее наблюдение создаёт задачу; выбранное значение сохраняется |
| Подмена снимка | Несовпадение SHA-256 отклоняется, транзакция откатывается |
| Публикация | Невыбранные импортированные расчётные ТТХ не попадают в действующую версию |
| Права | Клиенту закрыты страницы, снимки, модерация и источники; `role=admin` не даёт прав; регистрация — 404 |
| HTML | Контролируемая карточка разобрана; неподдерживаемый HTML и приватный IP дают ошибку, не фиктивный успех |
| Ручное дополнение | Источник без полной идентификации дополняется в связанную карточку без второго `robot` |
| Браузер | Edge, 1366×768 и 390×844; семь страниц на каждом размере, без ошибок JS и переполнения всей страницы |
| `scripts/verify_release.py` | Воспроизводимый прежний core: 17 роботов; исходный поток 54,75 — не проходит; улучшенный 131 — проходит |
| Замер core | Расчёт 0,001–0,0012 с, симуляция 0,0306–0,0718 с. Это локальные примеры, не SLA целевого сервера |

Семь проверенных страниц: главная, вход администратора, гостевой прежний модуль, база роботов, источники, создание проекта, карточка проверки наблюдений. Скриншоты находятся в `test-results/ui/`. Широкие таблицы имеют собственную горизонтальную прокрутку на телефоне.

Встроенный набор парсера: 5 моделей, 112 наблюдений, 5 предложений, 223 исходных строки каталога, 187 уникальных каталожных ID, 7 замечаний парсера, 10 неизвестных меток. Неизвестные метки дополнительно представлены задачами проверки. Ошибок источников в офлайн-наборе — 0. Валидатор JSONL возвращает `valid=true`.

Не проверены: реальные сайты всех производителей, обработка всех вариантов HTML, серверный PostgreSQL, Docker, серверный HTTPS, восстановление бэкапа, 50 одновременных пользователей. Браузерная проверка использует локального сотрудника без пригодного пароля, созданные проверкой сессии удаляются. Обновление Render, Git push и отправка данных внешним получателям не выполнялись.
