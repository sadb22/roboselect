# Roboselect — платформа оценки роботизации

Веб-платформа предварительной оценки роботизации. Полный сценарий: перемещение паллет на одноэтажном складе. Пользователь вводит параметры, выбирает оборудование, сравнивает текущий процесс, покупку и услугу, проверяет производительность дискретно-событийной симуляцией и сохраняет версионный отчёт.

## Запуск серверной версии

Для работы нужна только браузерная версия: устанавливать Python или скачивать репозиторий не требуется.

1. Откройте [платформу RoboSelect](https://roboscope-5562.onrender.com/).
2. Нажмите **«Вход как пользователь»**. Сразу откроется страница расчёта и визуализации решения, без промежуточных страниц.
3. Введите параметры объекта вручную или загрузите данные в поддерживаемом шаблоне XLSX/CSV. Выберите оборудование и сравните текущий процесс, покупку и услугу.
4. Запустите симуляцию, оцените производительность и посмотрите 2D-воспроизведение. Сохраните проект и выгрузите необходимые отчёты.

Для работы с данными роботов вернитесь на [стартовую страницу](https://roboscope-5562.onrender.com/) и выберите **«Вход как администратор»**. Откроется ассортимент: карточки оборудования, источники и проверка данных. В пользовательской роли административные операции недоступны.

Серверная демонстрация работает **без регистрации и паролей**. Выбор роли администратора доступен любому посетителю и не является проверкой его личности. Проекты привязаны к сессии браузера; для повторного доступа используйте тот же браузер с сохранёнными cookies. Подробнее: [режим свободного доступа](docs/PASSWORDLESS_DEMO.md).

## Возможности

Реализованы каталог, объяснение ограничений, ручное сравнение, импорт XLSX/CSV, экономика и чувствительность, 2D-воспроизведение, аккаунты, изоляция проектов, история версий, административный интерфейс, отчёты PDF/XLSX и выгрузка симуляции JSON/PNG. Для аэропорта и медучреждения доступны параметры и обзор решений. Внешние сайты не нужны для демонстрации.

Поддержка аккаунтов сохранена для режима с авторизацией; в текущей публичной демонстрации она заменена выбором роли без пароля. Импорт XLSX/CSV относится к базовому расчётному модулю. В расширенном складском проекте загрузка требований в форму выполняется по CSV-шаблону.
