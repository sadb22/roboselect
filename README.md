# Робоскоп

Актуальный модуль от 29 сентября: операции склада, смешанные конфигурации, симуляция, покупка и аренда без выкупа, модерация JSONL и согласование поставщиками. Руководство: [WORKFLOW_GUIDE.md](docs/WORKFLOW_GUIDE.md). При передаче работы: [HANDOFF_CURRENT.md](docs/HANDOFF_CURRENT.md).

Пример нового отчёта и документация находятся в [output/workflow](output/workflow). Воспроизведение: `python manage.py initialize_workflow`, затем `python scripts/export_workflow_demo.py`. Старые материалы непосредственно в output относятся к базовому модулю /legacy/.

Веб-платформа предварительной оценки роботизации. Полный сценарий: перемещение паллет на одноэтажном складе. Пользователь вводит параметры, выбирает оборудование, сравнивает текущий процесс, покупку и услугу, проверяет производительность дискретно-событийной симуляцией и сохраняет версионный отчёт.

Реализованы каталог, объяснение ограничений, ручное сравнение, импорт XLSX/CSV, экономика и чувствительность, 2D-воспроизведение, аккаунты, изоляция проектов, история версий, административный интерфейс, отчёты PDF/XLSX и выгрузка симуляции JSON/PNG. Для аэропорта и медучреждения доступны параметры и обзор решений. Внешние сайты не нужны для демонстрации.

## Локальный запуск

Требуется Python 3.12. В репозитории нет паролей или реальных клиентских данных.

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.lock
python scripts/dev.py
```

Открыть http://127.0.0.1:8765. Скрипт запускает веб-приложение и отдельный обработчик симуляций. SQLite используется только для локального демонстрационного запуска.

Создать администратора: `python manage.py createsuperuser`. Обычный пользователь регистрируется через интерфейс. Демонстрационный просмотр и расчёт доступны без регистрации.

## Развёртывание

Бесплатный стенд для тестирования команды: [RENDER_FREE.md](docs/RENDER_FREE.md). Конфигурация `render.yaml` создаёт приложение и PostgreSQL на плане Free. Есть сон после простоя и срок действия базы 30 дней.

Пошаговый запуск с PostgreSQL, HTTPS, автоматическим перезапуском и резервными копиями: [DEPLOYMENT.md](docs/DEPLOYMENT.md). Нужны сервер с Docker Compose и доменное имя, направленное на его публичный адрес. Исходный ориентир ресурсов: 4 vCPU, 8 ГБ RAM, 80 ГБ SSD; подтверждается нагрузочным тестом на целевом сервере.
